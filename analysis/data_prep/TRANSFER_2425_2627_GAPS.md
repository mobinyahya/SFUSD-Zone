# SY24-25 to SY26-27 data scenarios: what is missing and how it is resolved

The September 2026 SFUSD transfer
(`Data/raw_SFUSD_data_downloads/Sep 14 2026 data transfer/`) adds three school
years. This document is the standing account of what those years do **not**
contain, what the conversion does about each gap, and what residual risk that
leaves. The per-year machine-readable detail lives in
`sfusd_transfer_report_<year>.json` next to the converted tables, regenerated by
[`convert_sfusd_transfer.py`](convert_sfusd_transfer.py).

Registry years: `2425`, `2526`, `2627`.
Scenarios: `sfusd-2425`, `sfusd-2526`, `sfusd-2627`, `sfusd-2425-2627`.

## 1. What the transfer actually contains

Three CSVs per year, **students only**:

| File | Grain | Carries |
|---|---|---|
| `*_PreRun.csv` | one row per ranked choice | school, program, rank, per-request priority flags, tie-breaker random number |
| `*_PostRun.csv` | one row per student | assignment outcome, coordinates, attendance-area school |
| `*Demographics.csv` | one row per enrolment record | ethnicity, home language, address/ZIP |

There is **no** capacity file, **no** school table, **no** Census geography,
**no** block-level equity index, and **no** choice-model estimate. Everything
those feed is borrowed, derived, or left blank — itemised below.

## 3. Capacity substitutions

`--gaps fail` (the default) aborts and names these. They were accepted under
`--gaps fill-and-report`, and every affected row carries a `capacity_source`
column so the substitution is visible in the data, not only here.

| Year | Grade | Program | Capacity used |
|---|---|---|---|
| 2425 | 09 | `757-AF-09` | 1 (observed) |
| 2526 | KG | `453-MM-KG` | 1 (observed) |
| 2526 | 06 | `607-AF-06`, `858-MM-06` | 5, 1 (observed) |
| 2526 | 06 | `868-SA-06` | **0** — never assigned, no district row |
| 2526 | 09 | `559-AF-09`, `757-AF-09`, `832-TC-09`, `853-NS-09` | 4, 1, 2, 8 (observed) |
| 2627 | KG | `790-SA-KG` | 7 (observed) |
| 2627 | KG (Mission Bay) | `999-MM-KG` | 5 (observed) |
| 2627 | KG (Mission Bay) | `999-AF-KG` | **0** — never assigned, no district row |
| 2627 | 06 | `607-AF-06`, `858-MM-06` | 2, 2 (observed) |
| 2627 | 09 | `559-AF-09`, `757-AF-09` | 3, 5 (observed) |

An observed count is a **lower bound** on true capacity: an undersubscribed
program looks smaller than it is. The two rows at capacity 0 are effectively
closed programs in these scenarios. All are special or language programs, so a
`program_population: GE` run is unaffected.

## 4. The round label

This is the gap most likely to be misread, and it applies to **all three
years**, not one.

Established: the pre-run has no round column, and no student has a repeated
rank. So there is exactly **one preference list per student** — rounds are not
stacked together.

Not established: which round that list is. The demographics extract's
per-student `rounds_applied` field records a later round for a large minority:

| Year | KG applicants | recorded in a later round | breakdown |
|---|---|---|---|
| 2425 | 3,835 | 345 (9%) | `4`: 291, `999`: 54 |
| 2526 | 3,400 | 1,277 (38%) | `4`: 1,231, `905`: 17, `999`: 16, … |
| 2627 | 3,149 | 873 (28%) | `4`: 794, `999`: 27, `50`: 16, … |

(`4` is the amendment round; `50`/`666`/`888`/`902`/`905`/`999` are
administrative codes.)

The pre-run cannot be split by round: no column separates tagged from untagged
students, and `idRequest` spans the same range for both (2627 KG: tagged
min/median/max 11/34,820/60,160 vs untagged 41/33,932/60,711). So tagged rows
are not a later batch appended to the file — `rounds_applied` describes rounds
the student engaged with elsewhere, and those extra request rows are simply not
in the transfer.

**Consequence:** `rounds: [1]` is the only valid selector, but read it as "the
one list the district supplied", not "round 1". The checked-in years through
2023-24 carry genuine separate `r1_`/`r2_`/`r4_` blocks, so a per-round
comparison between a transfer year and 2023-24 is not meaningful.

## 5. Block equity indices have two vintages

The district recomputed these between 2018-19 and 2021-22. On the 3,652 Blocks
that 1819 and the newer years share, essentially every value differs; 2122,
2223 and 2324 agree with each other exactly.

`load_block_indices` therefore walks from the newest readable year backwards and
stops at the first disagreement, rather than taking a union. It used
**2324 + 2223 + 2122 = 4,207 Blocks** and recorded the cut-off at 1819.

`ctip1` is deliberately *not* in this lookup: it is not block-stable (28 Blocks
differ between 2223 and 2324), so it comes from the raw pre-run `CTIP1` column.

Residual: `student_1920.csv` and `student_2021.csv` were unreadable, so they
were skipped. They sit between 2122 and the 1819 cut-off, so if they were
readable and agreed they could extend Block coverage slightly. This is the one
gap in this document that would close purely by fixing file access.

## 6. Per-year missingness

Counts are students, out of all applicants for that year.

| | 2425 | 2526 | 2627 |
|---|---|---|---|
| Applicants | 14,133 | 14,892 | 14,870 |
| Kindergarten | 3,835 | 3,400 | 3,149 |
| No coordinates | **1,756** | 52 | 46 |
| Coordinates outside district Blocks | 4 | 69 | 87 |
| No `census_block` | 1,760 | 121 | 133 |
| No ethnicity | 2,900 | 1,018 | 3,216 |
| No home language | 2,832 | 900 | 3,132 |
| No `FRL Score` | 2,094 | 554 | 621 |
| No `HOCidx1` | 4,113 | 2,960 | 3,024 |
| In a Block the index lookup misses | 334 | 433 | 488 |
| Programs emitted (KG / KG+MB / 06 / 09) | 155 / 155 / 62 / 54 | 153 / 153 / 63 / 56 | 152 / 155 / 62 / 50 |

Two notes on reading this table:

- **2024-25 is the weak year.** 1,756 applicants (12.4%) have no post-run row
  at all, so they have no coordinates, no Block, no equity index, and no
  assignment outcome. Those students are dropped by the default
  `outside_district_students: ignore`.
- `optimization` fills blank `FRL` and `AALPI Score` with the column mean in
  `_load_students_for_year`. So a run over these years is not free of
  imputation — but this is the same behaviour the checked-in years already
  have, not something the transfer introduced.

## 7. SY26-27's post-run is truncated

It has 31 columns where 2425 has 50 and 2526 has 52, plus five empty trailing
columns (`AA`-`AE`) that look like a broken export. Absent relative to the
other years: `Distance`, `RequestStatus`, `RequestStatusReason`, `cohortString`,
`CohortScore`, `RequestRandomNumber`, `idCohortSet`, `Sped_Pathway`, and every
per-request tie-breaker (`MA`, `HA`, `BV`, `CTIP1`, `Sibling`, `CurrentLP`,
`CurrentLPsibling`, `AAPreK`, `PreK`, `MSF`, `NCLB`, …).

Impact is limited because the pre-run carries the tie-breakers the pipeline
actually reads; the one real loss is `r1_distance`, blank for all of 2026-27.
**Worth asking the district for a complete SY26-27 post-run.**

## 8. Decisions that were judgement, not transcription

| Decision | Why it was needed | What was done |
|---|---|---|
| Mission Bay ES `1731` → `999` | SY26-27 issues Mission Bay a new ID; the repo keys every Mission Bay policy on `{909, 999}`, so `include_mission_bay: false` would have silently retained it | Rewritten in the converter; 488 request rows. Gives the school the 2023-24 coordinates and the `999-GE-KG` capacity of 66 |
| `BAY` / `B2A` / `BRN` mapping | The transfer codes do not map by name onto `bayview_to_brown_ms` / `bayview_to_all_ms` / `brown_ms_to_hs` | Pinned empirically: `BAY` is grade-6-only and school-858-only; `B2A` is grade-6 across all middle schools; `BRN` is grade-9 across all high schools |
| `homelang` encoding | The transfer has full language names (`Cantonese`), the checked-in years have two-letter codes (`CC`) | Emitted as the full HLS1 name. The only consumer, `Students.get_qualified_programs_dict`, accepts both; HLS1's distribution matches the checked-in column most closely |
| Multi-school `MSF` | `msf` is a scalar school column and `Students.msf` grants priority at one school; the transfer lists two for 15 (2526) and 21 (2627) students | Kept the school at the student's lowest listed rank; the rest cannot be represented |
| Unlocatable school | 2627 grade 9 has one request for Independence HS (466), absent from the 2023-24 grade-9 school table | Request **and** program dropped together, so no student references a program the market does not know |
| Duplicate demographics rows | One row per enrolment record, so mid-year movers appear twice (584 / 22 / 42 students) | Kept the row with the most non-null fields |
| Blank demographics IDs | 450 (2425) and 1 (2526) rows carry no `scrambledstudentno` | Dropped — unattributable to any applicant |
| `enrolled_<year>.csv` = KG subset | The name suggests a population, but for 2122-2324 the checked-in `enrolled_*` is exactly the KG rows of `student_*` | Reproduced that convention. So `student_population: applicant` and `enrolled` give identical rows under `grades: [KG]` |

## 9. Verification

Run against the real data, all three years:

| Check | Result |
|---|---|
| Assignment table load, 12 year x grade x Mission Bay combos | 0 unknown ranked programs, 0 null capacities, 0 null school locations |
| Assignment simulation (DA, `status_quo_3`) | Runs and exports citywide metrics for all three years |
| Optimization ingestion, 16 population x vintage combos | All build area tables |
| Optimization solve (`6-zone-9`, `BlockGroup_1`, 2010 vintage) | FEASIBLE, contiguous, objective 87-89 vs 88 for the existing `summer-26-zoning` |
| Test suite | `loaders/tests` + `analysis/data_prep` green; converter tests run on a synthetic transfer and need no shared data |

## 10. Not caused by this work

- The example optimization config is INFEASIBLE at `BlockGroup_1` under
  `geography_vintage: "2020"`, and with `max_distance: 5` raises
  `NoCandidateZonesError` on a node 30 miles out. Both reproduce identically on
  the checked-in `summer-26-zoning`.
- `assignment/tests/test_slurm.py` fails in any fresh worktree because it reads
  a gitignored personal config.

## 11. Open items

1. **Move the data root off iCloud.** `/soalnas/share` resolves to
   `~/Documents/share`, which iCloud replicates, so files evict to contentless
   stubs. Reads then block for minutes and can fail with `Errno 89`, and a
   partially evicted shapefile silently yields geometry with no attributes. Set
   `SFUSD_DATA_ROOT` to a non-replicated path. This also stops `restricted`
   student data replicating to a personal iCloud account.
2. **Ask the district for a complete SY26-27 post-run** (§7).
3. **Ask whether a capacity file exists** for these years (§3), and whether
   `rounds_applied` means "also applied in" or "only applied in" (§4). A
   one-line answer to the second would turn an assumption into a fact.
4. **Fit a choice-model estimate on 24-27 preferences** before quoting welfare
   from these scenarios (§2 row 3).
